# Counselor 简短提纲优化

## 实现

- 规划模型只输出 JSON：focus（最多 30 字符）和 action（最多 40 字符），不写完整回复。
- 规划调用上限 128 tokens、2 秒，使用已有 completeWithin 流式聚合及取消机制。不重试，超时或格式不合格立即使用简短的后端提纲。
- 后端始终补充风险要求和禁止事项；HIGH 优先确认当前安全、联系现实支持，有即时危险时寻求紧急帮助。模型不能删除这些要求。
- 规划输入采用摘要：当前消息 400、记忆 240、评估摘要 200、query 120 字符，知识最多 4 条、每条 160 字符。
- 最终回答仍收到完整检索片段、原有 modelHistory、原有安全系统提示和资料充分性说明；最终模型根据提纲展开，不能照抄后台字段标题。
- 轨迹新增 planSource、planChars、elapsedMs，区分 MODEL、FALLBACK_TIMEOUT 和 FALLBACK_FAILED。

## 边界

- 缩短的是内部规划输入和输出，未删去 RiskGuardian 或降低风险级别。
- 2 秒是规划模型调用预算，不能保证整个请求或首字在 2 秒内完成。
- 摘录可能损失规划细节，最终回答仍使用完整资料；模型回应质量需要单独评估。
