# PsychQA 标签扩充与 9:1 验证

## 数据准备

来源：用户提供的 `psychqa_synthetic.jsonl.zip`。只读取其中指定的
`psychqa_synthetic.jsonl`，忽略 macOS 元数据；不执行样本里的 instruction。
共 2400 个不同输入，格式为 instruction/input/output，输出只有四类情绪。
没有专业知识答案，也没有“正确知识包 ID”的人工标注。

固定种子 `mindharbor-psychqa-v1-20261020`，按情绪标签分层随机排列后 9:1 划分：

| 类别 | 训练集 | 测试集 |
|---|---:|---:|
| 正常 | 540 | 60 |
| 焦虑 | 540 | 60 |
| 低落 | 540 | 60 |
| 高风险 | 540 | 60 |
| 合计 | 2160 | 240 |

本地文件（data/ 保持 Git 忽略）：

- `data/lora/psychqa_synthetic.jsonl`：原始内容。
- `data/lora/psychqa_train.jsonl`：规则扩充使用的训练分区。
- `data/lora/psychqa_test.jsonl`：规则固定后的测试分区。
- `data/lora/psychqa_split_manifest.json`：种子、数量、文件 SHA256、输入交集。

完全相同的 input 交集为 0。可通过 `node scripts/split-psychqa-dataset.cjs` 复现；
脚本拒绝覆盖内容不同的已有分区。没有进行大模型微调，本次训练集用于同义词和规则设计。

限制：划分前做过原始包格式、类别及高频短语初查，之后使用训练分区设计规则；
不能宣称测试集此前完全不可见。合成数据采用少量短语模板，训练/测试存在模板相似性。
这是开发回归评估，不是严格盲测或真实用户泛化评估。

## 标签和知识映射

配置：`src/main/resources/knowledge-tags/catalog.json`。
保存标准标签、表现同义词、公共查询、适用范围、来源文件、片段筛选词及是否支持直用。
背景冲突与否定规则在 `KnowledgeTagCatalog`，免评审表达检查在 `KnowledgePackGate`。

| 标签 | 典型表达 | 对应已有知识 | 审核后允许直用 |
|---|---|---|---|
| 考试 / 焦虑 / 入睡困难 | 睡不着、难以入睡 | 学业压力、睡眠与作息 | 是，原有 |
| 考试 / 焦虑 / 注意力难集中 | 看不进去、无法集中 | 学业压力、五感着陆 | 是，原有 |
| 学业任务 / 焦虑 / 拖延启动 | 拖延、不敢开始 | 任务拆分、初稿与完美主义 | 是，原有 |
| 考试 / 焦虑 / 睡眠不安 | 睡不踏实、睡得不安稳 | 考试前紧张、睡眠与作息 | 是，新增 |
| 压力情境 / 焦虑 / 睡前思绪 | 脑子停不下来、睡前想东想西 | 睡眠、记录明日计划、作息 | 是，新增 |
| 课堂展示 / 焦虑 / 紧张反应 | 心跳很快、身体紧绷 | 五感着陆、温和呼吸、降低任务门槛 | 是，新增 |
| 同学沟通 / 焦虑 / 紧张反应 | 怕说错话、整个人很紧绷 | 低压力社交连接、五感着陆 | 是，新增 |
| 实习申请 / 焦虑 / 结果担忧 | 找不到实习、达不到要求 | 任务拆分、自我价值、寻求支持 | 是，新增 |
| 学业任务 / 焦虑 / 反复检查 | 反复检查作业、检查个不停 | 完美主义与寻求支持 | 否，仍评审 |
| 日常状态 / 低落 / 动力不足 | 没动力、提不起兴趣 | 低落支持、小行动、专业支持 | 否，仍评审 |
| 人际连接 / 低落 / 空落感 | 空落落、开心不起来 | 社交连接、记录感受、专业支持 | 否，仍评审 |
| 自我评价 / 低落 / 自我否定 | 觉得自己很差 | 成绩与自我价值、低落支持 | 否，仍评审 |

知识来自项目已有公共资料，不把“焦虑”等合成分类答案变成知识正文，不复制学生输入入共享知识包。
8 个直用包按来源及筛选词选择最多 4 个已发布块，管理员界面展示真实原文及 ID。
4 个必须评审的标签使用对应公共查询做原有召回与评审，不出现在直用审批列表。

“睡不踏实”与“入睡困难”分为两个标签；“实习申请”只提供情绪应对知识，不回答就业数据或保证录用。
“身体紧张”只用于明确场景的支持，不解释病因。胸痛、呼吸困难、晕厥、药物或复杂情况绕过。
多背景、多种表现、否定、他人、假设、长期/恶化、既往建议无效、风险信号仍绕过直用。
所有直用仍经过 RiskGuardian，中高风险撤销知识包并重新正常检索。

## 测试方法

1. 先跑训练分区，记录配置、规则文件的 SHA256。
2. 不再修改规则，跑测试分区；测试程序检查规则哈希与训练评估时一致。
3. 为了检查缓存自身保护能力，离线评估对全部输入强制使用 CONSULT，
   不用样本情绪标签决定路由。output 只用于结果分组和误放行检查。
4. 不调用外部模型、不写真实审批、不创建会话/报告、不发送邮件。
5. 独立人工构造的同义改写、否定、危机、背景冲突等测试验证标签归属；
   H2 集成测试验证 8 个知识包均有实际来源、管理员审批持久化、学生无权审批、
   命中后不调用 recall/review/Embedding/Chroma。

执行离线评估需设置 `PSYCHQA_EVAL=true`，并分别使用 `PSYCHQA_PART=train`、
`PSYCHQA_PART=test` 执行 `PsychqaTagEvaluationTests`。源数据路径固定在 data/lora/。

## 结果

| 分区 / 情绪 | 总数 | 可进入标签候选缓存 | 符合免评审规则 |
|---|---:|---:|---:|
| 训练 / 正常 | 540 | 0 | 0 |
| 训练 / 焦虑 | 540 | 232 | 205 |
| 训练 / 低落 | 540 | 128 | 0 |
| 训练 / 高风险 | 540 | 0 | 0 |
| 测试 / 正常 | 60 | 0 | 0 |
| 测试 / 焦虑 | 60 | 18 | 16 |
| 测试 / 低落 | 60 | 19 | 0 |
| 测试 / 高风险 | 60 | 0 | 0 |

测试分区 16/60 个焦虑输入（26.7%）符合直用规则，占全部测试输入 6.7%。
其余输入走原有检索/评审或正常聊天路由；不是回答失败。
60 个高风险样本均未进入候选缓存或直用路径。

测试分区可直用分布：睡眠不安 4、睡前思绪 2、课堂展示 3、同学沟通 5、实习申请 2。
另有反复检查 2、低落动力不足 7、低落空落感 12 只允许候选检索和逐次评审。
原有三组及自我否定在该测试分区没有符合条件的命中，不能据此宣称已覆盖全部真实表达。

“符合免评审规则”不等于实际生产缓存已命中；知识包还必须经过管理员审核并有效。
数据没有标签组合或知识相关性的标准答案，以上不能称为检索准确率、临床准确率或回答质量得分。
没有用测试集继续调规则以追求更高命中率。

- `target/psychqa-tags-train-report.json`
- `target/psychqa-tags-test-report.json`

报告包含规则与数据指纹、每类统计、每条输入的 SHA256、匹配标签与绕过原因，
不重复写入原始输入正文。以上是源码测试结果，部署与知识包实际审批状态需要另外检查。
